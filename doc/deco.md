## ✅ 装饰元素清单（建议做成可复用组件/纹理）

### 1) 星盘几何（核心装饰）

- 同心圆（2–5 层）
- 弧形轨道（带少量断点）
- 刻度 / ticks（像仪器刻度）
- 节点星点（圆点/小菱形）
- 连接线（极细线）

**用法**：作为页面分区背景、卡片角落水印、标题区框架。
**规则**：线条必须细、低对比、低透明度（像“浮在玻璃下”）。

------

### 2) 月相与天体符号（辅助母题）

- 新月/上弦/满月 icon
- 小行星/环形行星轮廓
- 星芒（4/8 角，偏几何）

**用法**：标签、难度标识、筛选项图标、分隔符。
**规则**：不做写实天体，保持“符号化”。

------

### 3) 星尘颗粒 & 噪点纹理（氛围底）

- 细颗粒噪点（film grain）
- 星尘散点（极少量亮点）
- 星云渐变（大面积柔和云雾）

**用法**：背景、卡片底、段落分区背景。
**规则**：颗粒小、密度低；亮点不要像撒胡椒。

------

### 4) 点阵 / 半色调（你图里很关键）

- halftone 点阵块（矩形或渐隐）
- 点阵遮罩（从角落向中间淡出）
- 细网格（微弱坐标网）

**用法**：页面角落、右侧边栏、空白区平衡构图。
**规则**：点阵只做“结构感”，不要抢内容。

------

### 5) Glitch 装饰（只做“数据异常感”）

- 像素块（少量矩形色块）
- 断裂条（1–3 条细短条）
- 扫描线（极细、短暂）

**用法**：标题旁、分割线附近、hover/切换时短出现。
**规则**：静态页面里 glitch 元素要少；更多放在交互瞬间。

------

### 6) UI 仪器化细节（让它像观测系统）

- 角标 / corner brackets（四角定位框）
- 十字准星 / crosshair
- 小编号（#01 #02）
- 坐标点/经纬标记（极淡）

**用法**：卡片角、模块标题旁、筛选区边缘。
**规则**：用于“强调精密”，不要堆满。

------

## 📍 推荐放置位置（很实用）

### 页面背景（全局）

- 深蓝星云渐变 + 极轻颗粒
- 极淡坐标网格（只在大屏可见更好）
- 远处一层同心圆星盘（透明度很低）

### 顶部 Header / Hero

- 大型星盘弧线从左上/右上切入
- 标题下方用“轨道分隔线”（弧线+节点）
- 右侧留半色调点阵平衡

### 分区标题（模块 Header）

- 标题左侧一个小月相/星点 icon
- 标题下方一条细金线 + 2 个节点
- 角落加轻 corner bracket

### 卡片（Song Card）

- 卡片右上角：小星盘水印（淡）
- 卡片边缘：细描边（hover 才金）
- 卡片底部：一条短“扫描分割线”

### 排行榜/表格

- 行 hover：扫描线掠过
- 排名 Top：金色星芒/节点
- 表头：刻度感分割线（细线+小 ticks）

------

## 🎚️ 克制规则（避免变花）

- **装饰只占视觉权重的 10–20%**：主角永远是数据
- **一屏最多 2 种装饰主元素**（比如：星盘 + 点阵；或 网格 + corner）
- **金色装饰优先用于“关键点”**：节点、标题线、Top 排名
- 装饰透明度尽量低：**“看得到但不吵”**

------

## ❌ Don’t（装饰禁区）

- ❌ 写实星空照片直接铺底（会脏、也不统一）
- ❌ 大量星星贴纸/blingbling（会像壁纸）
- ❌ 装饰压住文字、穿过数据（可读性第一）
- ❌ 同时堆：星盘 + 网格 + 点阵 + glitch + 大光晕（必乱）
